# Jewchetti-secret
descripción: Jewchetti-secret es un proyecto de laboratorio de **Redes Tecnológicas** en el cual se construye una página web de venta de ropa y artículos de la comunidad judía. El sitio funciona como un e-commerce básico que permite navegar por productos, ver detalles y gestionar un carrito de compras, con un diseño responsive y una base de datos relacional para almacenar la información de productos y usuarios.
